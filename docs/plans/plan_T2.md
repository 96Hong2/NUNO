# plan_T2: 생년월일 입력, 트윈 여섯 고르기, 홈 무대

> 로드맵: `docs/roadmap.md` 「T2」 · 작성 2026-11-24 · 상태: 리뷰 반영

## 목표

처음 켠 사용자가 생년월일, 트윈, 스타일을 고르고 홈 무대에 그 트윈이 서게 한다.

## DoD (로드맵 원문, 번호는 이 파일에서 붙임)

- [ ] D1 [웹화면] 저장소가 빈 브라우저로 열면 「생년월일을 알려 주세요」 가 뜬다. 날짜가 골라져 있어 「다음」 이 바로 눌린다. (S1-1)
- [ ] D2 [웹화면] 위 화면은 새로고침하면 다시 뜨지 않는다. 마이 프로필에 생년월일이 보이지 않는다. (S1-1, S1-2)
- [ ] D3 [웹화면] 트윈 고르기의 아래 단추는 고르기 전 회색 「트윈을 골라 주세요」 다. 하린 카드를 누르면 「하린으로 시작」 으로 바뀐다. (C1)
- [ ] D4 [웹화면] 「실사」 와 「인형」 을 바꿔 가며 보면 트윈 카드가 모두 여섯 장이다. (S1-3)
- [ ] D5 [웹화면] 트윈 고르기의 왼쪽 위 X 를 누르면 홈으로 간다. 홈 무대에는 기본 트윈(plan_T2 에서 정함)의 기본 코디 사진이 선다. (C6)
- [ ] D6 [웹화면] 둘째 단계 오른쪽 위 「건너뛰기」 를 누르면 홈으로 가고, 홈 무대에 첫 단계에서 고른 트윈이 선다. (C6)
- [ ] D7 [웹화면] 홈 무대에 고른 트윈의 기본 코디 완성 사진이 흰 바탕 위에 선다. (C7)
- [ ] D8 [웹화면] 「트윈 바꾸기」 시트에서 세린을 고르면 홈 무대가 세린의 기본 코디 사진으로 바뀐다. (S1-5)
- [ ] D9 [웹화면] 홈 머리글에 종 단추가 있고 장바구니, 메시지, 검색창은 없다. 홈 시트 두 탭에 빈 상태 문구가 보인다. (S1-6, S1-7)
- [ ] D10 [DB] 「저장소 보기」 화면에 판 번호, 생년월일, 트윈 ID, 스타일 태그가 보인다. 새로고침 뒤에도 같다. (S1-4)
- [ ] D11 [웹화면] 온보딩을 건너뛰고 홈에 처음 오면 처음 둘러보기가 뜬다. 끝까지 넘기거나 닫으면 새로고침 뒤에 다시 뜨지 않는다.
- [ ] D12 [명령] 프리셋 여섯의 점과 마스크를 겹친 확인 그림이 저장소에 있다. 손으로 고친 트윈은 `plan_T2.md` 에 있다. (G2-9)
- [ ] D13 [iOS] 설치 뒤 인터넷에 한 번도 붙지 않은 아이폰에서 생년월일 입력부터 「트윈 바꾸기」 까지 된다. (S1-8)

## 확인한 사실 (2026-11-24)

- 기획 문서끼리 다른 곳은 개발 계획 v3 와 로드맵 DoD 를 따른다. 트윈 카드는 여섯 장이고, 홈 검색창은 없다. 「트윈 바꾸기」 시트는 프리셋 여섯을 보이고 「새 트윈 만들기」 는 숨긴다.
- 생년월일은 온보딩 단계 밖의 첫 실행 화면이다. 단계는 트윈 고르기(1, 왼쪽 위 X)와 스타일(2, 오른쪽 위 「건너뛰기」)이다. 점 넷 가운데 3, 4 는 T3, T4 단계 자리다.
- 와이어프레임은 건너뛰면 트윈을 처음 값으로 되돌린다. DoD 는 1단계에서 고른 트윈을 세운다. DoD 를 따른다.
- `@react-native-community/datetimepicker` 9.2.1(Expo 58 고정판)은 웹에서 null 을 그린다.
- 트윈 그림 최종본은 기획 폴더 `6_트윈_그림_원본` 에 있다. 기본 사진 여섯(약 1086x1448 PNG, 하린만 900x1205 JPG)과 기본 코디 원본(분홍 회색 배경)이다.
- 홈 무대용 흰 바탕 누끼는 와이어프레임 v26 빌드 원본(기획 폴더 `패션플랫폼/2_와이어프레임_옛판과_빌드원본/v26_최신판_빌드원본/src/res/uploads`)의 `tw17_cut_<키>_co.png` 다. 하린만 `tw17_cut_harin_p07.png` 이고 모두 599x802 투명 PNG 다. 기본 사진 앱 판은 같은 폴더의 `tw10_b_<키>.jpg`(900x1205)다.
- 하린 머리 모양(결정 D21)은 정해지지 않았다. 기본 사진은 묶은 머리, 기본 코디는 앞머리 있는 긴 머리다.
- 점 뽑기 실측: MediaPipe 1.2.3(파이썬 3.12)으로 여섯 장 모두 얼굴 점 478개와 몸 점 33개가 나왔다. 하린(실사)과 루루(인형)를 확대해 보니 눈, 코, 입, 윤곽에 맞았다. 손으로 고친 트윈은 없다.
- `e2e/tabs.spec.ts` 는 홈 탭 머리글이 「홈」 이고, 홈에서 role tab 이 하단 탭 셋뿐이기를 기대한다. 이 파일은 고치지 않는다.
- 기획자 지시(2026-11-24): 앱 크기 판과 원본을 모두 저장소에 넣는다. 사용권은 기획자가 확인했다. 이 지시로 기본 코디 여섯 장을 설치 파일에 넣는다(결정 D20 의 겨울 룩 제외 조항보다 뒤의 지시다).
- 기획자 지시(2026-11-24): 마이의 이름은 「이름 정하기」 로 직접 쓴다. 처음 둘러보기는 T2 화면만 3장으로 새로 쓴다. GLOSSARY 온보딩 줄은 DoD 에 맞춰 고친다. 검사 장치와 시험은 과하게 만들지 않는다.
