## 2. 개발 서버가 HTML 에 격리 헤더를 붙이는지 (pnpm web 을 띄우고 curl)
$ curl -s -D - -o /dev/null -H 'Accept: text/html' http://localhost:8090/ | grep -i cross-origin
(격리 헤더 없음)
$ curl -s -D - -o /dev/null -H 'Accept: text/html' http://localhost:8090/home | grep -i cross-origin
Cross-Origin-Embedder-Policy: credentialless
Cross-Origin-Opener-Policy: same-origin
$ curl -s -D - -o /dev/null -H 'Accept: text/html' http://localhost:8090/dev/storage | grep -i cross-origin
Cross-Origin-Embedder-Policy: credentialless
Cross-Origin-Opener-Policy: same-origin
풀이: / 는 Expo CLI 의 ManifestMiddleware 가 Metro 미들웨어보다 먼저 HTML 을 낸다.
metro.config.js 의 enhanceMiddleware 헤더는 Metro 뒤 미들웨어(번들, 자산, /home 같은 경로의 HTML)에만 붙는다.
app.json expo-router 플러그인 headers 는 server 출력용이라 single 출력의 개발 서버에는 쓰이지 않는다.
expo-sqlite 비동기 API 는 SharedArrayBuffer 를 쓰지 않아 격리 없이도 읽고 쓴다. sync API 만 격리가 필요하다.
