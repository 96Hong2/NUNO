## 3. Stop (.claude/hooks/stop.mjs)
통과는 출력 없이 exit 0, 막기는 stdout {"decision":"block","reason":…} 와 exit 0 이다. 입력에는 이미 막았는지 알리는 값을 넣어도 훅이 읽지 않는다.

$ Stop, cwd=<scratchpad>/wt-clean
