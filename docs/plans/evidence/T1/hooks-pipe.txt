## 3. Stop (.claude/hooks/stop.mjs)
통과는 출력 없이 exit 0, 막기는 stdout {"decision":"block","reason":…} 와 exit 0 이다. 입력에는 이미 막았는지 알리는 값을 넣어도 훅이 읽지 않는다.

### 3-1. 바뀐 것 없음: HEAD 로 만든 깨끗한 worktree 를 cwd 로 넘김 (검사 루트를 input.cwd 의 git 최상위로 잡는지도 본다)
git -C <scratchpad>/wt-clean status --porcelain: []
$ Stop, cwd=<scratchpad>/wt-clean
(출력 없음)
exit=0, 0초

### 3-2. docs 와 *.md 만 바뀜 (이 증거 파일과 D11.txt 가 추적 안 된 상태)
git status --porcelain: ?? docs/plans/evidence/T1/D11.txt ?? docs/plans/evidence/T1/hooks-pipe.txt 
$ Stop, cwd=저장소
(출력 없음)
exit=0, 0초

### 3-3. 타입 오류가 든 임시 파일
packages/twin/src/domain/probe.ts 를 만들었다. 내용: export const probe: number = "타입 오류";
$ Stop, cwd=저장소
{"decision":"block","reason":"verify:fast 실패: pnpm typecheck 단계.\npackages/twin/src/domain/probe.ts(1,14): error TS2322: Type 'string' is not assignable to type 'number'.\n타입 검사 실패: packages/twin/tsconfig.json\n고친 뒤 끝낸다."}
exit=0, 1초

같은 상태에서 한 번 더 (통과 해시가 없으니 다시 돌고 다시 막는다)

{"decision":"block","reason":"verify:fast 실패: pnpm typecheck 단계.\npackages/twin/src/domain/probe.ts(1,14): error TS2322: Type 'string' is not assignable to type 'number'.\n타입 검사 실패: packages/twin/tsconfig.json\n고친 뒤 끝낸다."}

### 3-5. 통과 해시: 오류 없는 코드 변경이 있을 때 첫 번은 verify:fast 를 돌고, 같은 상태의 둘째 번은 돌지 않는다
packages/twin/src/domain/probe-ok.ts 를 만들었다. 내용: export const probeOk = 1;
$ Stop 첫 번
(출력 없음)
exit=0, 3초

통과 해시 파일 .git/nuno-verify-ok: 81ea00c5ead11d77…

$ Stop 둘째 번 (같은 상태)
(출력 없음)
exit=0, 1초

밀리초로 다시 잼: 해시가 같으면 verify:fast 를 돌지 않는다
같은 상태 셋째 번: stdout=[] exit=0, 3517ms
probe-ok.ts 끝에 빈 줄을 더해 해시를 바꾼 뒤: stdout=[] exit=0, 3534ms
다시 같은 상태: stdout=[] exit=0, 3486ms

(위 세 줄은 잴 때마다 이 증거 파일에 줄을 더해 해시가 바뀐 경우다. 추적 안 된 docs 파일도 해시에 든다. 아래는 결과를 모아 두었다가 끝에 적었다)
해시가 바뀐 첫 번: stdout=[] exit=0, 3526ms
같은 상태 둘째 번: stdout=[] exit=0, 108ms
probe-ok.ts 끝에 빈 줄을 더한 뒤 첫 번: stdout=[] exit=0, 3545ms
같은 상태 둘째 번: stdout=[] exit=0, 106ms

### 3-6. 임시 파일을 모두 지운 뒤
git status --porcelain: ?? docs/plans/evidence/T1/D11.txt ?? docs/plans/evidence/T1/D8.txt ?? docs/plans/evidence/T1/hooks-pipe.txt 
임시 파일 probe-post.ts, probe.ts, probe-ok.ts 는 확인마다 rm 으로 하나씩 지웠다. 확인용 worktree 는 git worktree remove 로 지웠다.

## 요약
- PreToolUse 42건 모두 기대대로다. 필수 9건: --no-verify, -nm, push --no-verify, .claude/hooks 로 리디렉션, .github 편집, main 에 있는 시험 편집, 깨진 JSON 은 막고, 보통 commit 과 새 시험 Write 는 통과.
- PostToolUse: 고친 파일만 prettier 로 맞추고, 도메인 Date.now 린트 오류를 reason 으로 알렸다. 깨끗한 파일, .md, 깨진 JSON 은 출력 없음.
- Stop: 바뀐 것 없음과 docs 만 바뀜은 0초 통과. 타입 오류 파일이 있으면 pnpm typecheck 단계와 TS2322 줄로 막았다. 지운 뒤 통과. 같은 상태의 둘째 Stop 은 통과 해시로 약 0.1초.
