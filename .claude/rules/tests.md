# 시험

- 단위 시험은 순수 도메인의 성질과 돈, 기록, 동시성처럼 깨지면 크게 다치는 자리에만 둔다.
- 단위 시험 파일은 `*.test.ts` 나 `*.test.tsx` 로 그 패키지 `src` 안에 둔다. 밖에 두면 돌지 않는다.
- 목(mock)으로 격리하지 않는다. 시계, ID, 기기 DB 는 `@nuno/*/testing` 의 대역을 쓴다.
- 날짜는 고정 시계(`fixedClock`)로만 만든다. 시험에 오늘 날짜를 박지 않는다.
- 단위 시험의 `.only`, `.skip`, `skipIf`, `runIf`, 단언 없는 시험, 매처 없는 `expect` 는 린트가 막는다.
- e2e 시험에도 `.only` 와 `.skip` 을 쓰지 않는다.
- 실패하는 시험은 실패한 채로 두고 알린다.
- 기대값은 로드맵 DoD 와 명세에서 가져온다. 실제 출력을 베껴 기대값으로 쓰지 않는다.
- main 에 이미 있는 시험 파일은 고치지 않는다. 바꿔야 하면 먼저 묻는다.
- e2e 는 Playwright 로 Expo 웹을 띄우고, 요소는 화면에 보이는 이름으로 찾는다.
